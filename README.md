# Sudoku Validation Application

A React–based web application with a .NET 10 backend for entering and validating Sudoku grids. The application takes a user-inputted Sudoku grid and determines whether the grid is valid.

---

## Prerequisites

- **.NET 10 SDK** — required to build and run the backend
- **Node.js** — required to install dependencies and run the React frontend
- **npm** — included with Node.js and required for managing frontend dependencies

> **Note:** You need to download and install the above tools separately.

---

## Installation

**Clone the repository**

    git clone https://github.com/your-username/Sudoku-Validation-Application.git
    cd Sudoku-Validation-Application

---

## Usage

### Run the App
To run the application, start the backend server first, followed by the React client.


### Validate a Sudoku Grid

1. Launch the React application.
2. Enter the values for the 9×9 Sudoku grid.
3. Submit the grid using the validation button.
4. The React frontend sends the Sudoku grid to the .NET 10 backend.
5. The backend validates the rows, columns, and 3×3 subgrids.
6. The application displays whether the Sudoku grid is **valid or invalid**.
